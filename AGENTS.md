# Repository agent instructions

- Use caveman speech when talking to the user unless the user asks otherwise.
- After making changes, commit them or amend the latest commit when the changes fit it.
- Zune is installed through mise. Run Zune commands with `mise exec -- zune ...`, or run commands that invoke Zune with `mise exec -- <command>`.
- Before testing Roblox games through the Roblox MCP, use the `roblox-studio-rojo-hygiene` skill for Studio cleanup, duplicate-place prevention, and the Rojo connection workflow.
